# scraper/

华大 Wiki 的爬虫源码目录。

## 目标

从华大公开页面自动抽取资料，生成 `wiki/scraper/` 下的归档页面。

## 设计原则

1. **只爬公开页面**。教务系统、选课系统等需登录的不爬（密码/cookie 不进仓）
2. **原始数据落 `data/`**，不提交；产物（Markdown）落 `wiki/scraper/`
3. **每个爬虫一个文件**，名字 = 数据源（如 `jwc.py` 爬教务处）
4. **可重跑**。同一脚本两次跑结果一致，不依赖时间（除非显式声明）
5. **有 README 写"爬什么 / 频率 / 上次更新时间"**

## 暂定目标源

| 源 | 脚本 | 产出 | 状态 |
|----|------|------|------|
| 教务处通知 | `jwc.py` | `wiki/scraper/jwc.md` | ⏳ 待写 |
| 课程中心 | `courses.py` | `wiki/scraper/courses.md` | ⏳ 待写 |
| 图书馆数据库 | `library.py` | `wiki/scraper/library.md` | ⏳ 待写 |

## 第一个爬虫从哪里开始？

建议从**教务处通知**开始 —— 公开、不需登录、价值高（新生最关心）。

## 不做的事

- 不爬需要登录的页面（防封号 + 凭据安全）
- 不爬带版权的 PDF/视频（链接可以，文件不存）
- 不写分布式爬虫（华大规模小，单机够用）
- 不写反爬对抗（被封就停，问问能不能合作）
