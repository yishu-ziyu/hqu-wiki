# IFR 工业机器人数据

> 来源：国际机器人联合会（IFR），1993–2023 年

## 数据说明

IFR 全球机器人统计数据，包含各国工业机器人安装量数据。

### 文件

| 文件 | 格式 | 说明 |
|------|------|------|
| `IFR机器人数据robotics.xlsx` | Excel | 主数据表 |
| `IFR机器人数据robotics.dta` | Stata | Stata 格式 |
| `9月30日数据汇总.pdf` | PDF | 数据汇总说明 |
| `马克数据网-搜一搜与二维码.png` | 图片 | 数据来源说明 |
| `工业机器人渗透度测算方法参考/` | 目录 | 测算方法参考文件 |

## 数据结构

- 时间范围：1993–2023 年
- 面板单元：国家 / 地区
- 变量：工业机器人安装量

## 计算方法参考

`工业机器人渗透度测算方法参考/` 目录包含：
- 渗透度测算方法参考文档
- 国民经济行业代码匹配表
- 分行业就业人数数据（1999–2020 年）
- 相关学术文献

## 注意事项

- 数据来源为马克数据网整理
- 原始数据来自 IFR 官方统计
