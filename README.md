## 答辩PPT模板

> 来源：华大星球 · 第三期华侨大学PPT模板推荐。已去除"华大星球"占位文字水印，可直接替换为自己的内容。

| 文件 | 风格说明 |
|------|----------|
| `defense-ppt-01.pptx` | 通用答辩模板，36 页 |
| `defense-ppt-02.pptx` | 简洁风格，31 页 |
| `defense-ppt-03.pptx` | 完整风格，39 页（最大，含丰富素材） |
| `defense-ppt-04.pptx` | 汇报型模板，38 页（含"汇报人"占位） |
| `defense-ppt-05.pptx` | 中英双语标题，40 页 |
| `defense-ppt-06.pptx` | 紧凑型，20 页 |
| `defense-ppt-07.pptx` | 毕业答辩汇报，21 页 |
| `defense-ppt-08.pptx` | 经典风格，23 页 |
| `defense-ppt-09.pptx` | 标题页风格，21 页 |
| `defense-ppt-10.pptx` | 开题报告专用，31 页 |

**使用方式：** 打开 .pptx → 替换占位文字（如"答辩人""指导教师""XX学院"）→ 填入自己的论文内容。
