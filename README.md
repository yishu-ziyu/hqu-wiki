# 🎓 hqu-wiki

> 华侨大学 Wiki — 学生维护的实用指南。
>
> 选课、教务、生活、论文、答辩、资源入口。少官话，多实操。
>
> 内容由学生编写维护，**学校未参与**。准确性请以学校官方通知为准。

---

## 这不是

- 不是学校官方文档
- 不是课程资料集合（那是另一个仓的事）
- 不是鸡汤合集

## 这是

- 一个**学生写给学生**的 Wiki
- 选课 / 教务 / 生活的实操经验
- 论文 + 答辩模板（华大论文格式、10 套答辩 PPT）
- 一个**会接爬虫**的资料库（教务处、选课系统等自动归档）

## 怎么用

| 你是 | 怎么用 |
|------|--------|
| 刚入学 | 从 `wiki/manual/` 开始看，按需跳到具体条目 |
| 在选课 | `wiki/manual/选课.md` + `wiki/scraper/courses.md` |
| 写论文 | `wiki/thesis/` + `wiki/templates/` |
| 想贡献 | 任选一个"待补"页面，PR 一个 .md 进来 |

## 目录

```
wiki/
├── index.md          ← Wiki 首页
├── manual/           ← 手动维护的生活 / 教务条目
├── scraper/          ← 爬虫产出的归档页
├── thesis/           ← 论文模板（封面、格式规范）
├── templates/        ← 答辩 PPT 模板
└── tools/            ← 工具指南（Stata 等）
scraper/              ← 爬虫源码
data/                 ← 爬虫原始数据（gitignored）
reference/            ← 风格参考（gitignored）
```

## 贡献

最简单的方式：发现过时 / 错误 → 提 issue；有补充 → 直接 PR 一个 Markdown 文件。

写之前看 `wiki/index.md` 底部的**编辑约定** —— 不写官话、不写空话、不写鸡汤。

## 风格参考

质朴实用为主。立意上不照搬《上海交通大学生存手册》的反思维定式（华大 Wiki 是工具书不是檄文），但保留"读者立场、不端着、承认未知"这三个调子。
